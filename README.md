# 苏格拉底的提问方法｜思维闪电 · Socratic Rush

Mark & Daddy 独立小游戏系列 02。系列 01 Math Clash 的源文件、站点与数据库均保持原样。

- 45 秒单局，100 个原创三语场景。中文、英文、日文完整界面与题目。
- 2 选 1，点击或键盘 1/2、左右键。根据当前任务选择更有用的追问；不是宣称其他追问在所有场景都错误。
- 洗牌题库双方同种子、不重复；答案换边。前四题轻松热身，之后用另一种有价值的追问做干扰项。
- 正确得分 100 + 连击奖励（最高225）+ 反应奖励（最高50）；每五题双倍。答错自动揭示本轮更合适的追问并继续。
- 苏格拉底式提问的六类练习：澄清、证据、前提、视角、后果、反思。赛后只有一个默认收起的技能卡，可以复制追问去任何 AI 中尝试。没有必修教程。
- 独立 Cloudflare D1 保存房间与排行榜，约 0.9 秒更新 PK 比分。双方共享服务器开局时间；匿名玩家使用不公开的玩家凭证提交成绩。重复提交幂等、迟到的进度不会覆盖最终结果。
- 10 枚成就、5 个成长等级。成长数据以昵称存储于本设备，不跨设备同步；排行榜跨设备共享。再来一局次数、复制邀请次数保存在成长档案。
- 排行榜面向家庭友谊赛。分数由客户端报送，不是具备竞技级反作弊的官方赛事。

## 开发和验证

使用 Sites 插件安装、构建、打包与发布。Node >=22.13。

`node tests/content.mjs`：100 题及三语完整性、确定性题序、换边、技能与成就基础检查。

`node tests/api.mjs`：针对本地 `http://127.0.0.1:5175` 的完整约 50 秒联网测试，会写入带 QA 标识的测试成绩。可用 TEST_BASE 指定测试环境。

`npx tsc --noEmit`：类型检查。

`npm run build`：正式构建。`npm start -- --port 5175`：预览。

首次本地测试前按 drizzle/ 的顺序应用数据库迁移。Sites 发布时自动应用生产迁移。

## 许可与教学来源

`public/dopa/{audio,bg,fx,core}.js` 直接复用原 Math Clash 已引入的 [dopa-drill](https://github.com/grmchn/dopa-drill) MIT 代码。只修改了桥接命名，未引入 Dopakichi、原项目名称作为品牌或原 Logo。完整 MIT 与例外条款保存在 `public/dopa/LICENSE.txt`，页面底部可访问。字体遵循各自 OFL 声明。

原创题目参考 Foundation for Critical Thinking 对苏格拉底式追问的分类理念：
https://www.criticalthinking.org/pages/the-role-of-socratic-questioning-in-thinking-teaching-learning/522

本游戏练习快速识别追问。真实对话需要倾听、验证和连续追问；游戏分数不代表完整掌握哲学方法或 AI 使用能力。

## 产品验收

1. 一局结束后是否主动再来一局。
2. Mark 是否主动发出 PK 邀请。
3. 是否逐渐识别并在真实 AI 对话中使用更有效的追问。

前两项需由真实玩家试玩判断，不能用构建或正确率替代。
